# Verification outputs

These files were generated by `npm run verify` against a fresh in-memory PGlite PostgreSQL engine.

- `verification.json`: verification engine, dependency version, assertion count and dataset totals.
- `totals.csv`: source scale and revenue reconciliation totals.
- `quality_checks.csv`: eleven named SQL checks and their results.
- `monthly_performance.csv`: 24 complete calendar reporting months.
- `category_performance.csv`: sales, returns and merchandise margin by category.
- `channel_performance.csv`: signups, buyers, repeat purchasing and observed value.
- `cohort_retention.csv`: only observable cohort-month combinations.
- `product_ranking.csv`: category ranks and cumulative revenue shares.
- `customer_rfm.csv`: buyer-level descriptive RFM scores.
- `fanout_demonstration.csv`: naive versus correctly aggregated booked sales.
- `query_plans.txt`: before/after composite-index execution plans.

Dates are ISO `YYYY-MM-DD`. SQL NULL is an empty CSV cell. Money uses decimal CAD values. Output files are included as portfolio evidence; rerunning replaces them. Query plan timings and row estimates may vary, while data and analytical totals are deterministic.
